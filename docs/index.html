COMPACT-Bench: one budget axis for memory compaction in LLMs and agents

Every compaction method, from KV eviction to agent summaries, priced in the same unit: bytes of retained state per token of history. The results below are drawn from the per-generation records; hover anything.

Run it

pip install -e .                 # CUDA build of torch first
pip install -e ".[quant]"        # 4-bit NF4 weights

compactbench frontier    --model Qwen/Qwen3-1.7B --quant bf16
compactbench mechanisms  --model Qwen/Qwen3-1.7B --quant bf16
compactbench audit       --model Qwen/Qwen3-1.7B --quant bf16
compactbench reversibility --dense --model Qwen/Qwen3-1.7B

python scripts/export_site_data.py runs docs/data.js
    Every number on this page is recomputed from the released per-generation JSON records by scripts/export_site_data.py. No tracking, no external requests.
